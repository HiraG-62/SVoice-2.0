# voice-lab-tabs: voice-lab の操作画面のプレイヤー欄を人ごとのタブにする

`docs/specs/voice-lab.md` の操作画面（`backend/scripts/voiceLab/index.html`）の変更。ユーザーの要望「それぞれ人ごとにタブにして」。

## Fixed
- 「プレイヤー」欄の表（1 人 1 行＋折りたたみの「状態の編集」）を、**1 人 1 タブ**にする。
  - タブの見出し: ゲーマータグ。種類（聞き手 / ボット）と、ボットなら状態（起動中 / 参加中 / エラー）が見出しで分かること（小さなバッジや色でよい）。「送信に含める」が外れている人も見出しで分かること。
  - タブの中身: 種類、送信に含める、ボットの状態とメッセージ、全体発言（ボットのみ）、再起動（エラーのボットのみ）、削除、**全項目の編集欄（折りたたまずに常に表示）**。
  - 最後に「＋」のタブ（または見出しの横のボタン）で、追加のフォーム（ゲーマータグ・種類）を出す。
- 選んでいるタブは、500ms〜1 秒ごとの再描画や値の編集で変わらないこと。入力中の欄のフォーカスと値が、再描画で失われないこと。
- 選んでいた人を削除したら、隣のタブを選ぶ。追加したら、その人のタブを選ぶ。
- 「聞こえ方の判定」欄と聞き手の選択は今のまま（タブの選択とは連動させない）。
- API（`backend/scripts/voiceLab/server.ts`）・状態・ボットの振る舞いは変えない。
- 外部 CDN・フレームワークは使わない（素の HTML / JS のまま）。文言は日本語で短く。

### 編集してよいファイル

- 狭い画面でタブが多いときの扱い（横スクロールか折り返し）
